### Technologies

### Featured Projects

- [Kalah](https://github.com/vlwork/Kalah) — A cross-platform implementation of the classic Kalah board game.
- [OPDS Desk](https://github.com/vlwork/OPDS-Desk) — A Windows desktop client for browsing, searching, and downloading books from OPDS catalogs into a local library.
- [Nuclear Option Russian Localization](https://github.com/vlwork/NuclearOption-RussianLocalization) — A Russian localization for Nuclear Option based on BepInEx 5.
- [Proxmox btop Console Kiosk](https://github.com/vlwork/proxmox-btop-kiosk) — An installer for a persistent `btop` monitoring screen on the Proxmox VE / Debian `tty1` console.
- [VPS Audit — Researcher Universe Labs](https://github.com/vlwork/vps-audit-Researcher-Universe-Labs) — A bilingual Bash script for read-only security and system-state audits of Debian/Ubuntu VPS.
- [Clean Name for Linux](https://github.com/vlwork/clean-name-for-linux) — A PowerShell tool to preview and normalize filenames when moving files from Windows to Linux.
